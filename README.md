🎯 Project Overview
<p align="center"> 🚀 <strong>Cypress E2E Automation Framework</strong> automates <strong>End-to-End Testing</strong> for the <br> 🔗 <a href="https://ecommerce-playground.lambdatest.io/" target="_blank">LambdaTest Playground E-commerce Site</a>. </p> <br>
🔹 Key Features

✅ Fast & Reliable UI Testing with Cypress
✅ Mochawesome for Detailed Test Reporting
✅ CI/CD Integration using GitHub Actions
✅ Easy Setup with JavaScript & Node.js
🛠️ Tech Stack

🚀 Getting Started
📌 Prerequisites

✅ Ensure you have the following installed:

    🟢 Node.js (LTS version recommended)
    🔵 npm (Comes with Node.js)
    🟡 VS Code (or any preferred IDE)

📥 Installation

# Clone the repository
git clone https://github.com/Mahbub091/cypress_e2e_showcase.git
cd cypress_e2e_showcase

# Install dependencies
npm install

🎯 Running Tests
<div align="center"> <table> <tr> <th>🔥 Command</th> <th>⚡ Action</th> </tr> <tr> <td align="center"><code>npm run cy:test</code></td> <td align="center">Runs tests in <strong>headless mode</strong> (for CI/CD execution)</td> </tr> <tr> <td align="center"><code>npm run cy:open</code></td> <td align="center">Launches the <strong>Cypress GUI</strong> to run tests manually</td> </tr> </table> </div>
📊 Test Reports

📌 After execution, test reports can be found in:

cypress/reports

🔍 Mochawesome Reports provide:
✔ Test Execution Overview
✔ Pass/Fail Analysis
✔ Error Traces
