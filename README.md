🎯 Project Overview

🚀 Cypress E2E Automation Framework automates end-to-end testing for the
🔗 LambdaTest Playground E-commerce Site.

🔹 Key Features:
✔ Fast & Reliable UI testing with Cypress
✔ Mochawesome for detailed test reporting
✔ CI/CD Integration using GitHub Actions
✔ Easy Setup with JavaScript & Node.js
🛠️ Tech Stack
<table align="center"> <tr> <th>🏗️ Technology</th> <th>🚀 Purpose</th> </tr> <tr> <td><strong>Cypress</strong></td> <td>End-to-End Test Automation</td> </tr> <tr> <td><strong>JavaScript</strong></td> <td>Test Scripting Language</td> </tr> <tr> <td><strong>Mochawesome</strong></td> <td>Test Report Generation</td> </tr> <tr> <td><strong>GitHub Actions</strong></td> <td>CI/CD Integration</td> </tr> </table>
🚀 Getting Started
📌 Prerequisites

✅ Ensure you have the following installed:

    🟢 Node.js (LTS version recommended)
    🔵 npm (Comes with Node.js)
    🟡 VS Code (or any preferred IDE)

📥 Installation

🔻 Clone the repository:

git clone https://github.com/Mahbub091/cypress_e2e_showcase.git
cd cypress_e2e_showcase

🔻 Install dependencies:

npm install

🎯 Running Tests
<table align="center"> <tr> <th>🔥 Command</th> <th>⚡ Action</th> </tr> <tr> <td><code>npm run cy:test</code></td> <td>Runs tests in <strong>headless mode</strong> (for CI/CD execution)</td> </tr> <tr> <td><code>npm run cy:open</code></td> <td>Launches the <strong>Cypress GUI</strong> to run tests manually</td> </tr> </table>
📊 Test Reports

📌 After execution, test reports can be found in:

cypress/reports

🔍 Mochawesome Reports provide:
✔ Test Execution Overview
✔ Pass/Fail Analysis
✔ Error Traces
